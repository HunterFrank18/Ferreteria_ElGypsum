Existiran la base de datos llamada "Ferreteria"
Existiran 2 tablas
1. Usuarios
2. Productos/Mercancia

La tabla usuario tendra los componentes:
Id de Usuario
Nombre de Usuario
Contraseña de usuario
Usuario Admin y Usuario Empleado

La tabla Productos/Mercancia tendra los componentes:
Nombre del producto
Codigo producto (Opcional)
Cantidad producto (Existencia o no)
Descripcion

El Usuario Admin podra:
Ingresar mercancia, precios y cantidad y cuando un producto este en 0, solo el admin podra poner cuando esa mercancia ingrese, ejemplo no habia tapon de media y llego el pedido entonces el admin ingresara la cantidad.

El usuario Empleado podra:
Ver el inventario
Ver precios
